# Mobile (React Native / Expo)

- Inset-grouped screens (settings, menus, status sheets, file details, import) are
  built from `src/components/InsetGroup.tsx`.
- Never call synchronous `expo-file-system` APIs on a path the user waits on:
  `File.info()`, `File.delete()`, `Directory.info()`, `.create()`, `.list()` are
  blocking JSI calls. Use `RNFS.stat`, `RNFS.exists`, `RNFS.unlink`, `RNFS.mkdir`,
  `RNFS.readDir` from `react-native-fs`. The `File` and `Directory` constructors and
  `.text()` / `.bytes()` do not block.
- Screens, hooks, and managers reach the core only through the `app.*` facade. No
  `ops.*` calls, no SDK calls, no SQL.
- `ios/` and `android/` are generated by `expo prebuild` and gitignored. A diff that
  adds files under either is wrong.
- Native module sources live under `modules/<name>/{ios,android}/` and are tracked.
  Swift and Kotlin logic there needs a native unit test
  (`bun run mobile:test:native:ios` / `:android`).
