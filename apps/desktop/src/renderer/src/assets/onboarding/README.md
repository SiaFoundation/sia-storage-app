# Onboarding photos

The three photos in the onboarding pile are NASA images, which are in the
public domain and need no attribution. Each is cropped to 3:2 and scaled to
600 x 400. The ids are the ones images.nasa.gov lists them under.

| File         | NASA id                         | What it is                                     |
| ------------ | ------------------------------- | ---------------------------------------------- |
| `earth.jpg`  | `GSFC_20171208_Archive_e001386` | Blue Marble 2012, from the Suomi NPP satellite |
| `saturn.jpg` | `PIA06193`                      | Saturn, a mosaic from Cassini                  |
| `aurora.jpg` | `iss058e005282`                 | Earth at night with an aurora, from the ISS    |
